# Инсит. Тестовое задание на позицию Go Junior. Вариант 2.

## Text Processing Microservices

В рамках данного задания я реализовал микросервисное приложение на Go, состоящее из двух независимых сервисов:

Text Receiver — сервис приёма текста и управления процессом обработки

Text Analyzer — сервис анализа текста и расчёта статистики

Взаимодействие между сервисами реализовано по HTTP. Архитектура построена с учетом принципов Clean Architecture и разделения ответственности.

## Архитектурная идея

Я разделил систему на два сервиса, чтобы:

- разграничить ответственность (приём данных / обработка данных),

- продемонстрировать межсервисное взаимодействие,

- показать работу с внешним хранилищем,

- реализовать обработку сетевых ошибок и таймаутов.

Text Receiver отвечает за:

- приём входящих HTTP-запросов,

- валидацию данных,

- генерацию уникального ID операции,

- сохранение статуса обработки,

- отправку текста в Analyzer,

- предоставление статуса клиенту.

Text Analyzer отвечает исключительно за бизнес-логику анализа текста:

- подсчёт количества слов,

- количества символов,

- количества предложений,

- вычисление средней длины слова.

Такое разделение позволяет масштабировать сервисы независимо друг от друга.

## API

Text Receiver

POST /api/v1/text — отправка текста на анализ

GET /api/v1/status/{id} — получение статуса и результата

GET /api/v1/health — проверка работоспособности

Text Analyzer

POST /api/v1/analyze — анализ текста

GET /api/v1/health — проверка работоспособности

## Структура проекта

text_receiver/
text_analyzer/

В каждом сервисе я использовал слоистую структуру:

- cmd/ — точка входа

- internal/controllers — HTTP-обработчики

- internal/usecases — бизнес-логика

- internal/domain — доменные модели

- internal/adapters — работа с HTTP, Redis и внешними сервисами

- pkg/logger — инфраструктурные компоненты

## Запуск

Требуется язык Go
Установленный docker

Для запуска можно прописать в командной строке:

docker-compose up -d для запуска контейнера с redis

в /text_analyzer:
APP_ENV=development HTTP_SERVER_PORT=5913 go run cmd/main.go

в /text_receiver:
APP_ENV=development HTTP_SERVER_PORT=5912 REDIS_ADDR=localhost:6381 \
REDIS_PASSWORD={password} ANALYZER_CLIENT_URL=http://localhost:5913 \
go run cmd/main.go
